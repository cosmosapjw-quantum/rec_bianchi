# REC-HE-FRAME-BRIDGE-20260930

This is a standalone local finite-tilt tetrad and clock adapter for the fixed selected-He material-frame source library. It follows the locked T4 interface report §§4–8 and Dossier III §1.21 Eqs. (144)–(150). The metric is (-,+,+,+), material velocity is beta=v/c, and the boost is rotation-free. Source lookup energy is in eV; normal time is seconds and normal path length is meters.

`MaterialVelocity::new` requires finite beta with norm strictly below one. `normal_to_material_ray(E_n,e_n)` requires positive finite energy and a unit direction. It returns `E_m=D E_n`, the aberrated material direction, and `D=gamma(1-beta·e_n)=dt_m/dt_n`. Use `E_m` for all material source, threshold, table, line, and pair lookups. Two-photon partners each use their own Doppler factor. The adapter never enlarges the Jacobs q or D86 y source domains; missing coverage must stay typed missing coverage.

For occupation/coherency collision blocks, the caller first maps material Mat2 components to the physical normal screen using the existing BASS screen adapter. Only then call `normal_time_after_screen_map`, which multiplies by D, or `normal_length_after_screen_map`, which multiplies by D/c. These functions do not create a screen map or apply an E³ factor. A sharp material line at epsilon has normal support epsilon/D. `sharp_line_delta_jacobian` returns 1/D for the distribution-coordinate identity; it is separate from smooth RHS clock scaling and must be used once when representing the line as a normal-energy delta. Finite-bin/profile line integration remains a caller responsibility.

A homogeneous material proper-density source uses `(R-theta_U*n)/gamma`; an orbital Mat3 collision block uses `B/gamma`. Orbital basis rotation and connection remain on the inherited transport LHS. `material_four_force_to_normal` boosts the signed photon and matter four-forces as ordinary contravariant four-vectors into a distinct `NormalFourForce`, retaining the ledger's SI units `(power/c, momentum rate)` and the material event balance. A photon ray clock factor is never substituted for a material worldline clock factor.

All public numeric paths reject nonfinite inputs and nonfinite or underflowed nonzero arithmetic with `CoverageError`. An exactly zero collision remains zero. This module does not perform normal moment quadrature, transform angular measures or spectral intensity, add Maxwell species drift, update histories, or integrate a Bianchi solver. Passing its local tests is not full T4 Gate I, transport integration, source parity, or scientific admission.

The binary64 numerical domain is deliberately narrower than the physical subluminal domain. The constructor returns `NumericalDomainUncertain` when the roundoff conditioning estimate `4*epsilon/(1-beta^2)` exceeds `4096*epsilon` (approximately gamma greater than 32). This is a conservative computational refusal, not a physical velocity cutoff or an interval proof. Nonzero subnormal products and quotients are compared with a power-of-two-scaled evaluation against the same relative rounding budget; destructive loss is rejected, while accurately representable subnormal results are retained. No clipping or replacement physical zero is introduced.
