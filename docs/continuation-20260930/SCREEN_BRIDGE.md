# REC-HE-SCREEN-20260930

`ScreenTransform` is a local, physical screen component map for one normal/material photon ray at one event. It implements Dossier II §11 Eq. (135) with metric (-,+,+,+), beta=v/c and the rotation-free `MaterialVelocity` boost. The caller supplies finite orthonormal 3×2 screens transverse to the normal ray and its aberrated material ray. Their handedness is the caller's choice; both O(2) orientations are accepted. The bridge defines no Stokes convention.

For each normal screen column `b=(0,v)`, the module forms `b_g=b+(u·b)/D (1,e_n)`, where `u=(gamma,gamma beta)` and `D=gamma(1-beta·e_n)`. It boosts `b_g` with `normal_to_material_four_vector` and takes its material spatial components, checking their norm, transverse direction and vanishing time component. It then constructs `T[A][a]` as the material basis A dot transported normal basis a. The module does not project or renormalize these vectors.

For an occupation/coherency `Mat2` or a signed complex collision block, `normal_to_material` returns `T F_n T^T`; `material_to_normal` returns `T^T F_m T`. Negative collision entries and indefinite Hermitian blocks are legal. These are component maps, without `D`, `E³`, or an angular quadrature weight. For a material collision rate, first map its block to normal components and then call the associated `MaterialRay::normal_time_after_screen_map`, which applies `D` exactly once. The frame adapter's normal-length method analogously applies `D/c`. Normal-energy lookup continues to use `E_m=D E_n` from the same ray.

Malformed directions, screens and nonfinite blocks return `CoverageError::InvalidInput`; arithmetic overflow, destructive nonzero underflow, inaccurate subnormal results, and overlap orthogonality loss return `NumericalDomainUncertain`. The boosted screen also passes the existing `validate_screen` geometry check, which reports `InvalidInput` if its geometry fails. Accurately representable subnormal components can pass. There is no clipping or positivity projection. This local bridge does not perform native history transport, collision physics, angular weights, selected-He consumer integration or scientific admission.
