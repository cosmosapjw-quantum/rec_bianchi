For a reversible tracked/companion/2s event v=(1,s,-1), solve d=hF(y+d v/2) inside the physical extent interval (no clipping). Linear invariants c.v=0 hold by construction. Smooth rates in a neighborhood of the state give unique local midpoint branch for small h (IFT), local error O(h^3). Forward/reverse half-sweeps of these second-order event maps give a second-order reaction map. Reaction half / scatter SSPRK2 full / reaction half is second order for smooth finite graphs with valid stage positivity. No unconditional positivity: scalar decay gives (1-kh/2)/(1+kh/2); h*k>2 must be rejected. Failure is transactional. No assertion of stiffness-uniform error or L-stability.
