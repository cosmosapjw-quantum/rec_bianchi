# Frozen source inputs

The original source inputs remain at the repository paths fixed by
`../FROZEN_CONTRACT.md`; this unit does not duplicate or rewrite them. The
producer streams their immutable SHA256 identities before evaluating reference
quantities. Its small `SOURCE_BINDINGS.json` output contains all313 original
query records, exact source energy/constant identities and conversion rules.

Tagged CSV convention: META fields are key/value, VIRTUAL field2 is energy_eV.
Source CSV/native decimal tokens reconstruct binary64, then exact rational
conversion precedes any production or independent reference rounding.
