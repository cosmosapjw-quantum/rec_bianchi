## Reproduce

From this directory in a checkout containing parent REC #199 (`c10e97ab3178c423cc7699684b33e1730d26437a`):

```sh
python3 prepare_inputs.py
OPENBLAS_NUM_THREADS=1 python3 test_tetrad.py
OPENBLAS_NUM_THREADS=1 python3 run_native_tetrad.py
OPENBLAS_NUM_THREADS=1 python3 reviews/rec_tetrad_independent_check.py
```

Python 3 and NumPy are required. The first command copies byte-checked inputs from the inherited parent directory into the local layout expected by the exact reviewed code. It never changes original inputs. The runner writes derived rows locally and replaces runtime metadata in `results_tetrad/RESULT.json`; the source data and physical calculation remain pinned. The independent script writes its fresh report under `reviews/rerun/`, leaving the original review untouched.

This commit contains a 24-row scientific moment witness and full result/hash summaries. It does not add copies of the 81,920 raw input or derived angular arrays. The inherited original source arrays remain required for the full replay; the derived arrays can be regenerated by the command above and are retained in the central research backup.
