# R3O predictor 기억 프로브 — 그림 검토

선택한 최종 그림은 `plot_revision_002/predictor_memory_seed_response.png`이다.
원래 PNG/PDF와 배치 수정의 실행 기록을 보존했다. 수정본 PDF는 CPU 제한으로
저장이 중단되어 `.pdf.partial`로 분리했으며 사용할 산출물이 아니다.

## 목적과 캡션

해석해가 있는 affine scalar 식 `y' = -200 y + 100`, `y(0)=1`에서 원본
current/prev2 predictor의 초기 기억 변경에 따른 상태 차이를 그렸다.
간격은 `h=4.245e-5`, 각 궤적은 12회 갱신이다. baseline의 두 과거 RHS는
해석해의 입력 `-2h`, `-h`에서 계산했다. 세 변형은 prev2에 1을 더하기,
prev에 1을 더하기, 두 기억을 현재 RHS로 재설정하기이다.

(a)는 한 기억 성분을 바꿀 때 오차가 처음 들어오는 단계를 비교한다.
(b)는 두 기억을 동시에 바꾼 경우의 계산된 차이와, affine 차분식을 정확한
유리수로 계산한 응답을 비교한다. 세로축은 각 경우의 `h*seed_scale`로
나누었다. `seed_scale=max(abs(delta_prev2), abs(delta_prev))`이다.
작은 scalar 프로브의 유한 단계 결과이며 재결합 궤적이나 물리적 수렴 실행은 없다.

## 실제 점검과 최소 수정

| 우선순위 | 관측 | 조치·상태 |
|---|---|---|
| P0 | 도표는 scalar 갱신 및 그 차이를 표시하고 caption과 일치한다. | PASS |
| P1 | 첫 도표 (b)의 왼쪽 아래 범례가 늦은 단계 곡선과 가까웠다. | 오른쪽 위로 이동; 최종 PNG 직접 확인 PASS |
| P1 | 단일 열 약 90 mm를 위한 3.54-inch 폭, 9-point 기본 글자, 8-point 범례를 사용한다. | 최종 708×1100 PNG에서 잘림·겹침 없음 |
| P2 | (a)는 원/사각형과 색으로 구분; (b)는 실선과 빈 원으로 기준/계산을 구분한다. | 흑백에서도 구분 가능 |
| P3 | 같은 단계 축과 정규화 정의를 두 패널에 사용한다. | PASS |

최종 판정: **선택된 PNG PASS**. 원래 PDF에는 처음 범례 배치가 남아 있다.
수정본 PDF의 미완료는 자원 제한에 따른 산출물 저장 실패이며, scalar 프로브의
수치 검사나 입력 어댑터 검사 실패로 분류하지 않는다. 검토 방법은 구현자의
실제 이미지 확인이며 부모 작업의 독립 이중 검토를 대신하지 않는다.
