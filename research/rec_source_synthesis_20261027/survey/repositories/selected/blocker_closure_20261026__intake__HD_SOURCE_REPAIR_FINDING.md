## What the source actually promises

LAMDA's [HD page](https://home.strw.leidenuniv.nl/~moldata/HD.html) identifies CDMS version 2, December 2011, and a file dated 7 June 2021. Its [format specification](https://home.strw.leidenuniv.nl/~moldata/molformat.html) defines level energies in cm^-1 but treats the transition-frequency column as optional information unused by the program. Thus 35 Hz equality between those columns is an additional project requirement, not a stated LAMDA consistency guarantee. This does not relax the project requirement. The public text has nine decimal places in its energies and eight in GHz frequencies; the previously derived serialization bound is 34.9792458 Hz. Million-Hz residuals cannot be explained solely by that displayed rounding.

The [CDMS HD entry](https://cdms.astro.uni-koeln.de/cgi-bin/cdmsinfo?file=e003501.cat) was returned by web search as version 3, August 2026, with 12 lines and v=0 only. It describes a considerable revision of version 2: an Euler-type Hamiltonian initialized with the first 15 theoretical rotational dipole transitions of Jóźwiak, Cybulski and Wcisło (2020), then fitted with two low-order parameters released. It specifically warns about the quality of earlier high-J extrapolations. The predicted J=12–11 uncertainty is 2.77 MHz. This is a different source version, not a precision-only reformat of LAMDA v2. Exa's cached fetch of the same URL returned v2; live direct opens timed out. Therefore the v3 description is useful published metadata but is not a verified local v3 numerical deck. No claim is made that version mixing or measured-line replacement explains each original discrepancy.

## Concrete primary successor paths

1. Preferred compatible CDMS route: obtain the exact HD v3 SPFIT/SPCAT input and parameter/covariance deck (.lin/.par or .var plus .int), its Euler-Hamiltonian convention, and high-precision same-run v=0 J=0..8 term values and eight adjacent rotational predictions. [CDMS program documentation](https://cdms.astro.uni-koeln.de/classic/general) documents fitting both transition frequencies and term values and producing prediction and energy files. Default .cat and .egy serialization is insufficient for the 35 Hz bound; the earlier `HD_SUCCESSOR_PRECISION_GATE.md` retains that proof. No actual fitting deck was recovered here.

2. Independent theoretical successor: Jóźwiak et al., *JQSRT* 253 (2020) 107171, [DOI](https://doi.org/10.1016/j.jqsrt.2020.107171), [author-hosted paper](https://piotrwcislogroup.umk.pl/files/papers/oa/Jozwiak2020a.pdf). Section 7 and reference 45 identify supplementary positions/intensities for all 5129 dipole lines and 108320 hyperfine components. Central rovibrational frequencies come from H2SPECTRE, while hyperfine shifts are distinct. The [author's data explanation](https://hjozwiak-umk.github.io/hyperfine.html) and [H2SPECTRE code page](https://www.fuw.edu.pl/~krp/codes.html) explicitly identify code for both rovibrational levels and transition frequencies; the underlying level paper is [Komasa et al., PRA 100, 032519 (2019)](https://doi.org/10.1103/PhysRevA.100.032519). The numerical dipole archive and a precision-qualified v=0 term deck were not recovered. The public example central frequencies are rounded to 0.1 MHz, so copying the printed examples cannot establish 35 Hz closure.

The readily indexed [2021 dataset](https://doi.org/10.17632/79dppwdw4f.1) instead concerns HD quadrupole O/Q/S lines and hyperfine splittings. It must not be silently substituted for the requested rotational dipole R-branch source. [Cozijn et al. 2022](https://arxiv.org/abs/2205.13877), DOI 10.1103/PhysRevA.105.062823, provides a valuable experimental v=0 J=3 minus J=1 combination difference, not the complete nine-level/eight-transition deck. Its 30 kHz measurement uncertainty is a physical error estimate, distinct from a 35 Hz internal representation check.
