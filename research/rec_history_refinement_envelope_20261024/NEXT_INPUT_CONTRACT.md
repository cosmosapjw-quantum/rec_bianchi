## 필요한 입력

Source commit/archive·producer·전체 cosmology·energy grid·원자 상수·state convention을 bind한다. Eta origin과 node/step, photon input-state와 accepted output-state, query별 face-owned committed prefix를 확인한다. Native prefix 길이 조건과 retarded coordinate를 구별하고 strict upper exclusion을 유지한다.

Outgoing field/Wien reference/units와 scalar FLRW 또는 선택한 Bianchi frame·geodesic·direction owner를 명시한다. Angular integration이 필요하면 실제 distribution/measure/quadrature supplier도 필요하다. Full thermodynamic Jacobian은 별도 열린 입력이다.

같은 target/domain의 independently justified eps_fine_reference 또는 endpoint uncertainty와 whole-cell curvature/stability bound가 있어야 physical history admission을 판정한다. Endpoint/trajectory,interpolation,startup,event alignment,parameter transfer,characteristic/normalization,arithmetic error를 구분하고313queries와 사용자가 고정한 tolerance로 전달한다. Missing 값은null이다.

매개변수가 다른 데이터를 target로 운반하려면 실제 transport map과 parameter error bound가 필요하다. 같은 code 또는 작은 parameter 차이만으로 물리 identity를 같게 취급하지 않는다. M2를 sampled second difference로 대체하지 않는다.

1. Same-domain fine-reference bound가 공급되면 현재 direct query/B_upper를 재사용해 outward-rounded B_upper+eps_ref_cell을 구성한다. Source-owned query routing과 H01/02R의 기존 error transfer에 연결한다.
